# One idea, one week

Skill: `week-spread`. The board skill is `week-board`. Both read [brand/AGENTS.md](../brand/AGENTS.md) and [audience/AGENTS.md](../audience/AGENTS.md) first, and run [brand/taste.md](../brand/taste.md) before the set is handed over. A missing or blank `audience.local/ideal-follower.md` stops the week.

There is no object in Dreamstate called a weekly plan. A week here is a local brief plus drafts, then day marks if you ask for them.

## The brief

Copy `vault/week/brief.md` to `vault/week/<date>.md`. Fill:

- The idea, in one sentence the reader in `audience.local/ideal-follower.md` would recognize.
- The source: a page, a file in `vault/sources/`, or a note. If you cannot name it, the idea is not ready.
- The proof the pieces may use. Only lines that are already on the Proof page or in that source.
- Which pieces you want: record script, letter, X, LinkedIn, picture. Skip the ones you will not make.
- The day each piece is for. A day is a plan, not a publish time.

## Order

1. Write the brief and stop if the source is missing.
2. If you are filming, `record-script` first. The other pieces quote the script's claims, they do not add new ones.
3. `letter-draft`, `x-draft`, `linkedin-draft`, and `frame-build` from that same brief. Each file links the brief path.
4. `week-board` updates `vault/board.md` and, only if you ask, calls `social.content.plan` on drafts that already exist.
5. You read the set. You say yes per item before any schedule.

## Finding the idea

Use material you already have: a question a buyer asked, a Proof line, a note in `vault/notes/concepts.md`. `source-notes` is the skill when you need a sourced brief first.

Outlier posts are optional and easy to fake. `x-scan`, `video-pick`, and `thumb-patterns` accept only posts you paste or a Dreamstate read that returns them. They do not invent reach. If the read is to-check in the tool map, they say so and work from your files.

## What ships

A folder `vault/week/<date>/` with the brief and the piece paths. Dreamstate ids, if any, written on the brief after the create call returns them. No ids typed by hand.
