# Board

A save on the board is for LinkedIn, in draft, with a full readback, and only after the owner asks. On `vault/board.md` the line stays under Drafting. Leave `publish_date` empty.

Record returned ids on the brief. Close by naming where the folder is, which article text you adapted, where the cover HTML is, the pixel sizes, and which editor step is still open.

The cover is not a field on `article_create`. The owner can open that folder and drop the files in, following the numbers, inside LinkedIn's article editor.
