# Tokens

Colors and type come from filled `brand.local` tokens. Headline text uses `--headline-gradient` when that token is set, and `--color-accent` when it is not. `--color-accent-2` is the second accent.

Stop if that file is blank. Do not deliver the stand-in.

A number appears only when the post already states it. Lines are the post's own lines. Roles and tool names come from that source.

Never invent a station. A mark or a photo is allowed only from a file the owner supplied, and a photo stays unchanged.
