# Gates

Gates on `tools_run`, outside `params`: `mode`, `max_credits`, `idempotency_key`, `quote_hash`, `approved`.

`dry_run` first.

Show the quote, `quote_hash`, and the pages.

The yes must match.

Live repeats `quote_hash`, sets `max_credits` to that ceiling (`0` only when the quote is `0`), and sends a new `idempotency_key`.

`approved: true` only after yes.

A refused quote is a price.

Do not retry.

Live revises existing Ideal Customer, Proof, or Tone of Voice, not an existing Product Information page.

If a page is unseen, paste it before dry_run so the sourced lines stay.

Read the receipt.

Report id and revision.

If compose cannot run, pages were not written; keep the raw folder.

The only Dreamstate write is that compose, after the yes.

This skill does not search, fetch, enrich, watch, publish, schedule, enroll, or send.

Do not create a server, a worksheet, or a posts database.

A capture yes does not cover those.
