# Sources

Save exact material in a new dated folder under `vault/sources/`.

Copy a local file unchanged.

A fragment stays a fragment; the manifest says so.

Change pages only after the gates below.

In `origin.md`, record the producer, where it came from, the date on the material, the date saved, the files, whether it is whole or a fragment, and whether it is public.

If a field is unknown, write unknown.

Append path, date, and what it is to `vault/sources/README.md`.

Do not commit.

No credential, connection id, or prospect row in the interview or a tracked file.
