# Project note

Write a project note: source files, message, chosen output, edits, and decisions still open.

When speech sets the cut, keep a transcript whose times point at the source, and look at the picture at each decision.

When speech does not set the cut, a silence map can mark the ranges.

Speech-to-text and any generation step are optional outside tools.

They are not bundled, and each one bills on its own.
