# Render

Read the help for the tools installed here and follow the grammar it documents.

This skill ships no shared render script and no transcriber.

Make only the assets the request names.

Keep working files and the finished render out of the source folder.

`brand.local` matters when you add a title or an overlay.

It does not matter when you only mark cuts.

Render, watch, and revise until the piece matches the brief.

When a file was rendered, `check-short-export` is the last pass.

Hand over the export, the project note, and the edit list, and name the limits you know.

Do not generate a picture of the speaker.

A still, if you need one, is a frame of their footage.

Publishing, and any upload, is a separate yes.
