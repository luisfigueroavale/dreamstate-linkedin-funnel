# Derive voice rules

Derive voice rules from the owner's own samples and edits. Follow `docs/skill-frame.md`.

## Use when

- Use this when Tone of Voice or `brand.local/voice.md` is thin.

- It does not import another person's voice.

## Steps

1. Read `brand.local/identity.md`, `brand.local/voice.md`, and `vault/voice/` (`references/read.md`). If the voice file is missing, copy `brand/voice.md` to `brand.local/voice.md`.

2. Save a new sample in `vault/voice/` under its filename (`references/samples.md`).

3. Classify each path beside the file (`references/classify.md`).

4. Observe several samples before a rule (`references/observe.md`). One is tentative, not a universal style.

5. Write into existing `brand.local/voice.md` sections (`references/write.md`).

6. Write a calibration draft only when asked (`references/calibrate.md`). Read `audience.local/ideal-follower.md` first.

7. Hand back the guide (`references/empty.md`). This skill does not post, send, or spend.

## Dreamstate tools

None. Local files only.

## Stop rules

- Template prompts are not owner rules.

- If unread, say so.

- Voice rules go only in `brand.local/voice.md`.

- No formats file, second guide, index, or log.

- Do not summarize, commit, or fetch a public post as a stand-in.

- Do not invent a sample or a quote.

- External inspiration is not a rule or example.

- A spoken habit is not a writing rule unless written samples show it.

- Do not hard-code a dialect, slang quota, CTA frequency, numeric separator, or hook length unless samples repeat it.

- Stop if `audience.local/ideal-follower.md` is missing or blank before a calibration draft.

- Add no unstated fact.

- Do not mark an imitation approved.

- Leave `Status: blank` until they say the rules are theirs.

- Do not claim a voice from a biography or `brand.local/identity.md` alone.

- This skill does not post, send, or spend.

- It does not import another person's voice.
