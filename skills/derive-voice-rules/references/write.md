# Write

Write into existing `brand.local/voice.md` sections. A cross-sample pattern is a rule. Keep an irregular habit samples show.

Struck words go under Banned words.

Every rule names two or more example posts, by link or by sample filename in `vault/voice/`. A rule with one example is marked tentative. A rule with no example does not go in.

Under Do, note any pattern from `docs/ai-tells.md` the owner's own posts really use, such as a closing question, with the examples. A drafting skill keeps that pattern for this owner. The long dash never stays.

Leave `Status: blank` at the top of `brand.local/voice.md`. The owner flips it to `Status: filled` when the rules are theirs.
