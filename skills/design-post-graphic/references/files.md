# Files

A carousel is 5 to 12 slides. Stay at 7 unless the brief gives a reason in range: hook, problem, idea's frame, slide per step, close. Give each slide one job. Keep a continuous sequence. The footer shows the slide number.

The portrait file is `pictures/frames/portrait.html`. Each slide file is `pictures/frames/carousel-slide.html`, one file per slide. The thumbnail file is `pictures/frames/thumb.html`. Replace the shell copy. Show a next step only when the brief has one worth taking.

A giveaway uses a connect line and the comment keyword you will reply to. Otherwise ask them to save it.

Keep the HTML in a named folder, or with that post's pictures. Save the editable HTML beside `export/`. On a thumbnail, and on any frame a profile image will cover, keep type inside the safe inset. Check that crop.
