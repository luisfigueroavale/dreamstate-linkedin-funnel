# Sizes

Take sizes from `docs/picture-rules.md` unless `brand.local/style.md` filled that row and `brand.local/tokens.css` mirrors it. A portrait and each slide are 1080×1350, at 1x and 2x. The phone check uses width 390. The thumbnail is 1280×720.

The MP4 is 1080×1350, H.264, 25 fps, `yuv420p`, faststart. The GIF is 720×900, 15 fps, palette, under 5 MB. A blank style row uses this table; say so. These export targets are for this repo. Look up the live platform limit when needed. Ask only when an open question would change the words or the format.
