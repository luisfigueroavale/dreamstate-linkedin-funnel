# Inspect

Inspect 1280×720 and 320×180 for readability, crop, contrast, and truth.

A manifest beside the HTML can set width 1280, height 720, and phoneWidth 320 so `npm run still` writes both views.

`review-graphic` is the pass when they want a separate review. Do not spawn extra agents unless they asked.

Return the export, the HTML source, the real dimensions, and any upload limit you did not verify. `docs/picture-rules.md` lists this repo's export target.

Making the thumb does not upload it or publish it.
