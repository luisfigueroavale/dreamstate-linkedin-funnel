# Metal title

A large name across a face starts from `pictures/frames/metal-title.css`, class `metal-title`.

The fill is `--headline-gradient` when that token is set, and `--color-accent` when it is not. `--color-accent-2` is the second accent an owner can name inside the gradient.

Leave both unset in the committed template.

Tracking is a small negative em, and the end padding clears the last stem.

Two shadows do the separation: a short contact blur, and a longer lift in a blue-black. There is no stroke, bevel, or inner highlight.

At 1280×720 the name is one or two words on one line, across the middle half of the frame, set low, and it does not cover the eyes. Size it on the page until that fit holds.

It does not stand in for a hook style the owner already approved.

Add `metal-title--soft` on the same element when one shadow is the better fit. That modifier uses one shadow. The fill stays the headline gradient or the accent.
