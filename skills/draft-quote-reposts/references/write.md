# Write

A quote adds something the source post does not have: the owner's own example, a number from their Proof page, a disagreement they can back, or the next step. Restating the post is not a quote.

Keep it short. One to three sentences usually carries it. The source post shows under the quote, so do not summarize it.

Use the owner's voice from `brand.local/voice.md`. Run `docs/ai-tells.md` and the banned words over every quote. No hashtags unless the owner's own posts use them. No closing question bait unless the owner's own posts do it.
