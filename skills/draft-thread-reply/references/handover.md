# Hand over

Route each thread, then three blocks. When a thread is ready, name the channel, the account, the recipient, the thread link, the point of the latest line, the fit evidence, the route, and the draft in a fenced block so breaks remain. Also name the person.

When a thread is held, name the missing fact.

Then give counts of answered threads and of noise. Put buyers first. Inside one route, older thread first.

At the end, report what went out, what you skipped, what failed, and what you held. Tally a sent link apart from a signup, a first product action, and a booking that was actually qualified.

A repeating pass may build the queue on a short interval the owner chose. Outside the repo, store last run, open drafts, each judgment, and a private do-not-answer list.

Advance the marker only after each fetched thread is handled or held. Approval stays until they name cases that may send.

The morning list shows each interested or still-unanswered thread as a name, one line they last wrote, the route, and the link. Ask which to draft.
