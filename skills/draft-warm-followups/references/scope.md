# Scope

A sequence is a new conversation, even with one recipient; cadenced outreach; or outreach to more than one recipient.

An existing thread goes to `draft-thread-reply`.

Email with no cadence is not a sequence.

A public comment goes to `draft-linkedin-comments`.

A file request goes to `send-lead-magnet`, and the file goes first.

Fit does not condition handoff.

Do not activate in the same step as delivering the file.
