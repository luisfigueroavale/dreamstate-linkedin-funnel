# Connectors

Compute each end from the card's current box. Bind both ends: the line names the cards, and each card names the line. Bind the shape the line actually meets. Leave room for the exit label. They stay off the type and off other cards.

Draw the path that succeeds first. Then draw failures and loops. A long return runs outside the main column. A failure or a return may be dashed so the main path stays clear. When two columns sit side by side, say on the map whether the work runs at the same time. Side by side alone is layout.

A feedback line starts where the feedback appears and ends on the station that changes because of it. Leave a raw source card as evidence. A later sale stays on the result.
