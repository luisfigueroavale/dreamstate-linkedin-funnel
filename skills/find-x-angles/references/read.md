# Where to read

Cheapest first: posts and links they pasted, then the browser, then `visibility.radar.inspiration_x_list`. That radar read is free. It takes `query`, `author_handles`, `ai_filter`, `limit`, `cursor`. `tools_get` before `tools_run`. The fetched schema wins. Sending dry_run still executes the read.

Keep `limit` to a short page, about 10 to 20, and name the number you asked for. Pass `cursor` only when you mean to open the next page, and say so. `ai_filter` is a short description for this call.

A reason in the response applies to this response only.

The tool's order is not an engagement ranking. Sort the set you hold. In the browser you can use that site's own search operators and a date range. That string is a different dialect from the radar query. Do not paste it into the radar call and expect the same filter.

Pass known accounts through `author_handles`. Ask for original posts unless you are reading replies on purpose. If one account fills the page, query the remaining handles on their own. A person quoted in the text is not the account you requested. For the owner's own recent posts, pass their handle and keep originals.

There is no paid command-line client and no third-party search product in this skill. Use the radar read or files they supplied. Prefer a saved file under `vault/sources/` before you pay to pull the same posts again, and label the capture date on every saved number.
