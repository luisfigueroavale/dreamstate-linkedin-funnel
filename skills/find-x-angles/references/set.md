# The set

Turn the question into a topic, a problem the reader has, and, when it helps, a named builder or a concrete workflow. The seeds above are optional. Start from original posts. Include replies when you want buyer language, an objection, a failure, or the steps someone took.

Read the post, the media, and the thread before you say why it traveled. Open a linked doc, repo, or benchmark when the post depends on one. A cut-off snippet is not the post. Confirm a cited post at the source before you treat a number or a quotation as fact.

Dedupe on post id. Keep a row that fits the reader, shows a real mechanism, has a discussion worth joining, and leaves the owner an angle their evidence can carry. Do not drop a row because the like count is low. Modest reach stays when the problem is real.

Read a reply before you infer the mood from a count.

Likes, bookmarks, replies, and reposts stay separate. Quotes stay separate when the tool returns them. A missing view count is unknown. Do not write zero in its place. A zero the tool returned stays zero, and it is still not proof the post reached nobody.

Followers, when a paste or a tool returned them, are context beside age. Do not invent either.
