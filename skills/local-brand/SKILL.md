# Fill the local brand

Read `brand/AGENTS.md` first. Copy templates into `brand.local/` if the copies are missing. Ask the blank lines in batches: identity and voice, then style and tokens, then assets. Write a value only after the owner states it. Leave unknowns empty. Do not invent a hex color, a font, or a proof line.

Mirror style into `brand.local/tokens.css` using the names in `brand/tokens.css`. Replace `unset` only for tokens they set. `Status: filled` is theirs to set.

Before you call the files ready, run `brand/taste.md` on any sample sentence you placed in the files.
