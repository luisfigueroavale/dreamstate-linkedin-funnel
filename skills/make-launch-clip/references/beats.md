# Beats

Beat sheet: spoken line, visual action, the evidence or asset, and a target duration. The spoken line has to be true of the feature on that screen. Do not invent a metric. Use assets they already have. Do not generate footage.

Every screen is a real feature, or it is labeled concept or demo. Keep the script next to the scene source so a revision cannot leave them apart. Narration text and beat times live in one file.
