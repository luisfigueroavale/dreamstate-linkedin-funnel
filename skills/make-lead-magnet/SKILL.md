Follow `docs/skill-frame.md`.

Read `audience/AGENTS.md`, then `audience.local/ideal-follower.md`, and `brand.local/identity.md`. If a required file is missing or `Status: blank`, stop. The follower file is the reader. The offer is the Ideal Customer page. Printable claims come from the Proof page. Name each page and any revision returned. If Proof is unread, use no number and no result. No figure from another company's customers. Do not paste Company Context, either page, or the follower file into the giveaway.

Put the next job first. That job is a decision, a calculation, a workflow they can configure, or a draft they can finish. `promise.md` is one sentence naming the output they hold when done.

Use a calculator for a repeated decision. Use a template when the work returns. Use a repository when the workflow runs or needs configuration. Use a checklist when inspection has a clear stop. Use a guide when the method needs steps in words. A hosted page is not the format for every request.

`magnets/<slug>/` follows `magnets/example/`. Replace every line. No leftover example sentence. A later reader restarts from the same blank.

- `promise.md`: that sentence.
- `example.md`: a full pass to that output. First line says example. An invented figure is marked invented, not a customer's result, with no customer numbers.
- Copyable blank: `blank.md`, or the sheet, checklist, template, or repository, with `blank.md` pointing at it. They can edit it.
- `delivery.md`: the keyword, the full URL, and the sentence that carries that URL. Use no short link. Keep the existing UTM. If it is unpublished, the address is unknown. Do not invent an address.
- `README.md`: who it is for, the problem, the promise, the pieces, the first result, and the setup. Setup names every tool, account, cost, install, price, and unsupported step. Add a published stable address. After the first result, one optional next step. Extras stay after that.

`README.md` gets a stranger to that result, then the check: bad input, a skipped named requirement, and what failure shows. It pays off the promise. A sales conversation is not a step. They finish with you out of the room.

Read as that stranger. Cut a step whose login, account, or tool is unnamed beside setup. Open every promised file and link. Unknown is not a promised link. Remove or replace a link that does not open. Do not message anyone to test the path. If a script is missing, delete that sentence. For a repository, make a fresh copy, run it, and read the files it wrote. For a document, read the export through. For a sheet, test an empty cell, a zero, and a row past the last designed. Done when one result is reachable alone. A preview is a preview, and a scaffold is a scaffold. Neither is a working integration.

Hand the folder over. No send, post, enroll, keyword arm, or outside board. Publishing is a separate yes. This skill does not publish. An own launch post goes to `write-linkedin-post` or `write-x-post` once the folder exists. Do not send that post.

Before the owner sees it, confirm the points above. Nothing was sent.
