# Pillars

Each pillar has a promise and a boundary, and one job from `vault/notes/funnel-stages.md`: reach, belief, or signup.

Pillars that cover the same ground get split, or the note says why the overlap stays. Build them from recurring reader needs and from experience the owner can show.

Topics are recurring questions inside a pillar. Subtopics are sourced angles, and only when a file or a Proof line supports the angle.

A name you suggest stays a proposal until the owner adopts it. The template sentence in the pillar note is not a taxonomy.
