# Pillars

Each pillar has a promise and a boundary, and one job from `vault/notes/funnel-stages.md`: reach, belief, or signup. Do not edit those job definitions.

Pillars that cover the same ground get split, or the note says why the overlap stays. Build them from recurring reader needs and from experience the owner can show.

Topics are recurring questions inside a pillar. Subtopics are sourced angles, and only when a file or a Proof line supports the angle.

The 4x4x4 scaffold is a starting grid, not a duty to invent 64 ideas. Stop when the sourced questions run out.

A name you suggest stays a proposal until the owner adopts it. An existing taxonomy stays unless they asked to revise. The template sentence in the pillar note is not a taxonomy.
