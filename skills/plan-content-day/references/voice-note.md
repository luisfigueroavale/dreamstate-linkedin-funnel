# Idea or voice note

The owner can send an idea in a line, a link, or a voice note any day.

1. Save the words to `vault/sources/<date>-note.md`. For a voice note, use the transcript the owner or the host supplies. Keep their words.
2. Find the one idea in it. If there are two, ask which one leads, or make two sets.
3. Hand the idea to `write-x-post` for one X post, and to `write-linkedin-post` for one LinkedIn draft tagged reach, belief, or signup.
4. Add a tap-to-post link to the X post with `node scripts/intent-link.mjs`.
5. Run `docs/ai-tells.md` and the banned words. Hand both drafts back.

Do not add a claim, a number, or a story the owner did not say. Nothing is scheduled or posted.
