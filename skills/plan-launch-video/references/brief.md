# Brief

Read `brand/AGENTS.md`, `brand.local/identity.md`, `brand.local/voice.md`, `audience/AGENTS.md`, and `audience.local/ideal-follower.md`. A missing or blank file means stop and ask.

Fill what you can from what the owner supplied, then ask only for what changes a claim:

| Field | What it decides |
|---|---|
| What works today | What can be shown on screen |
| Viewer and buyer | Who must recognize the problem at once |
| Wanted result | The change the viewer wants |
| Current painful way | The task, cost, or mistake to show |
| Obvious alternative | Why switch from it, or from doing nothing |
| Visible difference | Which on-screen behavior proves it |
| Proof on hand | Real outputs, measured results, customer words with permission |
| Action and destination | What the right viewer does next |
| Channel, length, aspect | How fast proof must land, and the frame |
| Date and assets | What can be finished |

A product page is a claim, not proof of behavior. If no product is supplied, return the blank plan, not an invented one.
