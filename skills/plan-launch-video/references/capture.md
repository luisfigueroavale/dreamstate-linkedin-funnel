# Capture list

Copy `references/templates/capture-list.md`. One shot per ledger line. Per shot: starting state, input, exact actions, output, capture range with handles, crop, cursor path, and the ledger line it proves.

Use a clean demo account with realistic data. Nothing private on screen: no real contact, inbox, deal, or customer record. There is no exception, so use demo data instead.

Label every shot: real time, sped up, waiting cut, illustration, concept, or demo. A label that changes what the viewer believes goes on screen, not only in the notes.

Keep the picture moving with purpose: a push, a crop to the control, a pan to the output. No flat screenshot held for ten seconds. Give the output enough time to read at phone size.

Captions, emphasis text, and real UI text must agree and must not cover each other.
