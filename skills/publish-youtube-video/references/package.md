# Package

Read the finished file on disk, the title, the description, the thumbnail, and any privacy, schedule, or time zone they named. If the file, the title, the description, or the thumbnail is missing, ask.

Use one video per post. The title is `platform_payloads.youtube.snippet.title`, 100 characters or fewer. The description is `snippet.description`, 5000 characters or fewer. Privacy is always set in `status.privacyStatus`: `private`, `unlisted`, or `public`.
