# Look

Read the brief and the post this frame came from. Read filled files in `brand.local/` that the piece actually uses. Skip context that cannot change the verdict.

If identity, voice, style, or tokens are missing or still blank, review clarity and execution only. Do not invent a compliance failure, and do not invent a color or a font to fill the gap.

Look at the rendered file. A description of it is not the review. Check full size, then the file at 390px wide.

If style left the size row blank, a portrait is 1080×1350 and a thumbnail is 1280×720.

On a carousel, review every slide, not a sample, and check that the run still reads as one piece. A contact sheet is not a review.

If you only have a screenshot, separate what is visible from checks that need the HTML.

For a second ratio, judge aspect-ratio recomposition: hierarchy and crops made for that frame, not a flat shrink of the first.
