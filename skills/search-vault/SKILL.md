# Search the vault

Search the local vault before drafting and add a concept back after the owner accepts a piece.
Follow `docs/skill-frame.md`.

## Use when

- Use when you need a prior note, before a draft or a claim about the owner's prior work.

- Not for a Dreamstate call.

## Steps

1. Start at `vault/README.md` (`references/search.md`).

2. Read (`references/search.md`).

3. Treat a page marked `Status: blank`, an empty note, and a template prompt as unanswered prompts (`references/blanks.md`).

4. Search (`references/scope.md`).

5. Add (`references/accept.md`).
## Dreamstate tools

None. Local files only.

## Stop rules

- A page marked `Status: blank`, an empty note, and a template prompt are unanswered prompts.

- Example files are not the owner's work.

- Do not install software or a global server to answer a search.

- A current fact from outside this desk stays open.

- This search does not establish it.

- No Dreamstate call.

- Do not add a metric.
