# Unanswered prompts

A page marked `Status: blank`, an empty note, and a template prompt are unanswered prompts.

Owner context is a line the owner supplied.

The same holds for a blank template under `brand/` or `audience/`: the frame reads `brand.local/` and `audience.local/`, and this search does not treat the template as a vault note.

`vault/posts/sample-gate.md` is an example.

The README files in `vault/voice/` and `vault/sources/` only index those folders.

A sample counts when the owner supplied that file.
