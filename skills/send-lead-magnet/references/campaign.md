# Other campaigns

For another campaign, before a new file message to a first-degree person, check whether an active send on this network already has them. Open means pending, active, waiting on a connection, waiting on a signal, or another sender owns them. If the tool is missing, search, then call `tools_get`.

If the full list is cut short, read the active slice once. If it is still cut short, refuse. Do not guess. Page each open status by 25. A short page is not the full list.

Mark them aside. Do not recheck them the same day. Look again after a day. The preview still has a credit ceiling.
