# Duplicate guard

Run the duplicate guard. Check the worksheet row, then replies under the comment, then the private thread. Hand-handled people are done, keyed by provider id, so the rule leaves them alone. If `social.outreach.keyword_dm_sends.list` already shows this destination, do not also send it by hand.

The sent line must include sent, inbox, or dm as a whole word, or a later pass will miss it and write again. Vary the wording by a hash of the person so a retry repeats the sentence. Every variant passes that word test. The connect-first line must not include those words.

A connect-first line already on the comment is not proof the file went out. If a reply is already there and passes the word test, stop. Read at most three reply pages under one comment. Only a one-to-one chat counts.

Read at most two chat pages, twenty at a time. Proof is a message you sent that is still present and contains the destination. Read about the last twenty messages. An accepted send not yet on the read-back stays unverified.
