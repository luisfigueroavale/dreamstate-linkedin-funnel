# Failed pass

On a failed pass, an uncertain public write on a busy post ends the pass on purpose. Keep public lines behind file messages. Reconcile by reading each thread. Reset a row that never posted and clear its saved intent. A scheduled pass fails when a tick calls a date constructor or the clock.

Read the ISO text. The local checker reads that text without those calls and does not send. A large enrollment read that is cut short forces the campaign check to refuse. If quota enforcement is unavailable, stop. Do not build a side path that does the same writes. Tell the owner.

On a failure, read `runs_get` and `runs_events`. Take the error from the last event. Do not invent a field the schema lacks.
