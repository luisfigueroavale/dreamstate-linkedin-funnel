# Failed pass

On a failed pass, an uncertain public write on a busy post ends the pass on purpose. Keep public lines behind file messages. Reconcile by reading each thread. Reset a row that never posted and clear its saved intent. A scheduled pass fails when a tick calls a date constructor or the clock.

Read the ISO text. The local checker reads that text without those calls and does not send. A large enrollment read that is cut short forces the campaign check to refuse. Tell the owner.

Take the error from the last event.
