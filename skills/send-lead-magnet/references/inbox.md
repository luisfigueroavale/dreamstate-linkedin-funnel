# Direct messages

Find threads with `unibox.inbox.unified_list` since the post went live. Keep a keyword match whose outbound text does not already hold the destination URL. A keyword hit is not always a request. Drop subject-only threads and threads already answered.

Draft with `draft-thread-reply`, in the owner's voice. Show the queue. Send only accepted texts, oldest first, a few minutes apart. Before each send, reread the thread for the URL. The comment rule may have delivered the file in between.
