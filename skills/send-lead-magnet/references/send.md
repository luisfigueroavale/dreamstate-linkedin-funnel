# Send order

Send the file message first. Read it back. Then send the public line. Save intent on the worksheet before every external write. Do not keep the status only in memory. Without that column, the first real comment has nothing to reconcile against. Empty previews can still pass.

An uncertain send is reviewed, not repeated. Finish private messages before any public line, so a timeout only cuts the tail. A do-not-contact flag blocks only a new file message. If the suppression tool is missing, search, then call `tools_get`.

About five hundred rows on a page means the page is incomplete. Match provider id or profile slug, ignoring a trailing slash and query. A flag that only records an inbound reply does not block the file they asked for. After the file is verified, their reply stops later automation.

The public line still goes out.
