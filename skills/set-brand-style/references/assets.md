# Assets

Licensed assets live under `brand.local/assets/`.

The README there is the allow-list.

Do not install example assets as defaults.

`pictures/examples` is not a starter kit.

Do not vendor fonts.

Fonts are files the owner listed in that README.

Otherwise say the system face is the fallback.

`scripts/frame-page.mjs` waits on `document.fonts.ready` after `goto`.

Screenshots stay faithful to the real product.
