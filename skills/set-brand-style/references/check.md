# Check

Use `npm run check`, and render through `scripts/frame-page.mjs` (`npm run still` or `npm run capture`).

Do not assume a script or a template from another repo is on disk.

A skill-only edit does not regenerate brand files; check this folder and its links.

If a capture helper changed, export one small scene into a temporary folder and inspect it.

When you look, check that the font loaded, that type is not clipped, that contrast holds, and that asset paths still resolve from `brand.local/assets`.

If a picture was produced another way, check it with the tool that built it.

Hand back the files you changed, whether each line is still draft or the owner set filled, and any consumer or font path that still has the old value.
