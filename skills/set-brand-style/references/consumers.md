# Consumers

Before a token change, list consumers and say which renders are stale: `pictures/frames`, `pictures/timeline.js`, `pictures/examples`, `scripts/frame-page.mjs`, `design-post-graphic`, `draw-process-map`, `review-graphic`.

Check the font file those actually load, and this skill's description.

Editing the body alone does not finish the change.

A renamed font in docs is not done if the renderer still loads the old file.

Shared CSS can change old renders, so keep the delivered file, or pin the values it used, when that picture must stay as it shipped.

On adoption, update the style words, the matching token values, and those consumers together, and only inside the scope they named.

If a layout idea came from another skill or an example, name that source in the local file.

Do not install that look as this owner's identity.
