# Identity

One owner file for intent is `brand.local/identity.md`.

On a first identity, record the impression they want, the constraints they named, assets they already hold, and where the look will be used.

Read the Company Context pages that file names, and `audience.local/ideal-follower.md`, before a rule depends on them.

Use only references they supplied.

Voice stays in `brand.local/voice.md` (lines they dictated; `derive-voice-rules` derives rules).

Link those pages.

Do not paste them into identity.

Read order stays `brand/AGENTS.md`.

Do not add a navigation page.

Offer a direction only when they asked for design work.

Label proposals draft until the owner adopts them.

Leave `Status: blank` until that yes, then set `Status: filled` and show them the file.

The adopted lines in that file are the record.
