# Tokens

Visual usage rules, in words, go in `brand.local/style.md`.

Put exact values in `brand.local/tokens.css` only, under names from `brand/tokens.css`.

Those names include `--color-accent-2` and `--headline-gradient`.

Headline text uses the gradient when the owner set it, and `--color-accent` when that value is still unset.

Do not rename a token.

Do not write a value into the committed file.

Do not copy the preview stand-in palette into the local token file.

Add a role only when a picture you are making needs it.

Layouts may differ.

They share those type and color roles.

Keep source tokens, blank templates, draft tries, generated renders, and delivered files in separate places.
