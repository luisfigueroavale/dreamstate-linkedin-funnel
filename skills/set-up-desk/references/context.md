# Context

Lasting buyer, proof, and voice go on Company Context. Each page needs `source_url` or `provenance_note`. `collect-owner-context` writes them.

Do not call `knowledge.brain.context.compose_pages` here. Do not call `knowledge.vault.ingest` for those pages.

Do not add a second database. Use Company Context plus the local vault. Refuse another database, views, or a parent page in another product.

Do not add a config for one. Do not copy an id from a sample, another workspace, or a search result. If pages already hold their words, leave them.
