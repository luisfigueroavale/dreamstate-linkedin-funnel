# Plugin

On the first session, work in this order.

Confirm the plugin before any write. `skills_list` must show dreamstate. If not, stop and point at `npx @trydreamstate/cli install`, or the marketplace.

Do not add a second MCP server. The endpoint is the URL in `.mcp.json`. Do not put an API key in the repo or a local file. Sign in through the browser.

`whoami` must show one workspace. If more than one is listed, ask and stop until it is named.

If the workspace is wrong, or a later call switches it, stop. Name it in chat only. Write no name or id into the repo. If you stop, copy nothing.
