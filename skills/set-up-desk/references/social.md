# First content pass

Everything here is a read or a local draft. Nothing posts, likes, follows, DMs, schedules, or spends.

1. Ask for the owner's X handle and LinkedIn profile URL. Write them under Accounts in `brand.local/identity.md`. Never write either into a tracked file. If they have no X account, skip the X reads and say so.
2. Run `derive-voice-rules`. It reads the owner's own last 100 or so X originals with the public X reads the host has (or the browser), takes LinkedIn posts they paste, and writes rules into `brand.local/voice.md`, each tied to example posts. Show the owner the rules. The file stays `Status: blank` until they say the rules are theirs and flip it.
3. When identity, voice, and the follower file are filled, run `find-x-angles` for a first viral read of the owner's space: last 7 days, held to `docs/viral-bar.md`, every angle with its link and counts.
4. After that read, run `plan-content-day` for a first plan in `work/plans/<date>-day.md`.
5. If a gate is still blank, stop at that step and name it as the next step in the check report.

A plan every morning is a routine. Ask whether they want one, and do not create it here. It needs the owner's yes on that routine and a reason they will read it every time.
