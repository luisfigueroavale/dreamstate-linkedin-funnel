# Hand off

The CTA matches the current offer in `brand.local/identity.md` and that piece's funnel job. When attribution helps the reader, name the original source in the piece.

If the source supports fewer, deliver that smaller count and explain the shortfall.

Outside the copy, write the source-to-piece map: one line per piece, with the point, the section or timestamp, the pillar, the funnel job, and the format.

On a week, add that map to `vault/week/<date>.md`. When they ask to store a piece, `social.content.artifact_create` saves that draft and does not post.
