name: station-map
description: "Draw a process as numbered HTML plates in reading order, with connectors that do not cross. Use for a flow, a funnel, or a system map. It does not publish."
---

Follow `docs/skill-frame.md`.

Shapes: source (a fact enters), step (something changes), skill (who does the work), decision diamond (yes or no), result (what is now true). One icon per role. Use a file from `brand.local` when one is listed; otherwise a simple CSS mark you name in the file. A like is not intent. Do not draw a diamond that says they will buy because they reacted. Connectors do not cross. If the map moves, the motion is `DeskTimeline`.
