# Cadence

Use the dates, time zone, channel, and cadence they named.

Do not pin the work to a standing set of weekdays.

A dated plan needs a time zone and a cadence.

If either is missing, ask for the pair in a single question.

If the channel is also missing, ask for it in that same question.

An undated batch can proceed with neither.

One LinkedIn post a day once a date exists.

When two LinkedIn pieces share a date, keep one and list the other as still open.
