# File

Read the titles and days already on the board and in `vault/posts/` before you add a line.

A finished draft is filed under Drafting.

A piece not written yet stays under Idea.

The planned day is recorded on the week brief (`vault/week/<date>.md`, copied from `vault/week/brief.md`).

For each piece, report the day or undated, the pillar, the topic, the funnel job, and the vault path, plus anything still waiting on the owner.

If a tool call returned an artifact id, report that id.

The board line is the path only.

Do not copy the post body onto the board.

When a write looks unclear, read the file again before you add a second line.
