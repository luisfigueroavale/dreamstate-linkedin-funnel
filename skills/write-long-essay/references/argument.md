# One argument

Name the question the reader is actually asking, and the answer this piece can support.

The brief sets the format and the length.

Do not pad to a made-up count.

Make one argument.

Map the argument before drafting: thesis, the claims that hold it up, the evidence for each, one counterpoint or limit, and what the reader can do with it.

Before drafting, check the source behind each claim.

If the evidence is missing, narrow the thesis or label the line a hypothesis.
