# Shape of the issue

Keep one useful idea and its promise to this reader.

Earlier editions set the format.

Use four moves, in order: an opening observation, an explanation or a worked example, a practical application, and one next step.

The explanation keeps the source's sequence.

Add a heading only when it helps the reader.

Name the guest whose experience you use.

Put opinion and evidence in separate sentences.

A metric names its population, its period, and its source.

Put a missing quote or fact on the source list, outside the body.

Paragraphs add information.

Keep the owner's distinctive phrasing.

Cut transitions that only announce the next move, and cut generic lessons the source did not earn.

The subject and the preview promise what the issue delivers.

The preview promises what the subject did not already say.
