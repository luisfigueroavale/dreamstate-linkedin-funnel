# Budgets

These are house budgets, not a feed preview. They are not a platform cap. They keep the point in a short opening a phone can show. Wrapping, a blank line, and the viewport change what a person sees.

Line 1 is a soft 40-60. A line at 35 or 85 can win. Line 1 stands alone. The point is not waiting after code point 140.

The opening block runs from the start through the second nonempty line, or through the only nonempty line, and that block aims at about 140. Spaces and line breaks inside it count. Stress-check 210 on the full text. The whole post, finished draft included, stays within 3000 code points.
