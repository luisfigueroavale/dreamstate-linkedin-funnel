# Tools

`social.content.generate_hooks` is free, with required `user_request` and `platform`, and dry_run is allowed. Fetch it with `tools_get` before `tools_run`. Its lines are candidates. Measure them. They do not add a number the owner does not have.

`social.draft_score` is a free read, with required `text`. Fetch it with `tools_get` before `tools_run`. Sending dry_run executes the read. Say that it was a read. It does not replace the measurer, and it is not a preview of the feed.
