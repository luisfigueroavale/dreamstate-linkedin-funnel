# Calls

Call `whoami` before the first spend. Call `tools_get` before `tools_run`. Call prices and modes are in `docs/calls.md`.

Use `visibility.research.web_search` when local files leave the question open. `query` is required. `max_results` and `include_domains` are optional.

Use `visibility.research.urls_fetch` for a known URL. `urls` is required. `max_characters` is optional.

See `docs/sources.md`.
