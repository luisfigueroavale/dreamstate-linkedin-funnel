# Write a video description

Write a paste-ready description, links, and chapters from the finished cut or a transcript that already has times. Follow `docs/skill-frame.md`.

## Use when

- Use this after the cut exists, or when a transcript already carries times.

- It does not upload or invent a timestamp.

## Steps

1. Read the promise on the brief and the offer links the owner already wrote (`references/opener.md`).

2. Write (`references/opener.md`).

3. Include (`references/links.md`).

4. Set (`references/links.md`).

5. Take (`references/chapters.md`).

6. Hand (`references/handoff.md`).
## Dreamstate tools

None. Local files only.

## Stop rules

- Follow the skill-frame writing rules.

- If the only text is a script, or a transcript with no times, mark each time provisional.

- Do not treat those lines as finished chapters.

- Do not add another sentence to the opener.

- Do not pack extra search phrases into the opener.

- Do not close the opener with a hashtag block.

- Never shorten that address.

- Leave every other site free of those parameters.

- Do not make up a sponsor, a file to download, or a product the brief does not name.

- Do not invent a timestamp or a view count.

- This skill does not upload.
