---
name: write-video-description
description: "Write a paste-ready description, links, and chapters from the finished cut or a transcript that already has times. Use after the cut exists. It does not upload or invent a timestamp."
---

Follow `docs/skill-frame.md`.

Start from the finished cut, or from a transcript that already carries times. Read the promise on the brief and the offer links the owner already wrote. If the only text is a script, or a transcript with no times, mark each time provisional. Do not treat those lines as finished chapters.

The opener is one sentence and no more than about 16 words. It says what the video is. Build that sentence from the phrase a stranger would type, and name the main tool when the video actually uses one. Search results and the collapsed description both show this sentence alone. The links, the next step, and the chapters come after it. Do not add another sentence to the opener. Do not pack extra search phrases into it. Do not close it with a hashtag block. A count or a metric, and any roster of tools, stays inside the video and inside the chapter labels.

Include a resource when it helps this video. Each one has a URL you opened and a label that says what the viewer gets. A video resource uses the full https watch URL, `https://www.youtube.com/watch?v=` plus the id. Never shorten that address. On the owner's own site, set `utm_source=youtube` and set `utm_campaign` to the weekly campaign slug on the brief, so a signup from this video lands on that week. A link written for the pinned comment carries its own `utm_content`. Leave every other site free of those parameters. Copy any disclosure or credit that is already in the brief. End with one next step the brief already supports. Do not make up a sponsor, a file to download, or a product the brief does not name.

When the cut exists, take chapter starts from it. Keep the order the cut has, and name each stretch for what it shows. Where a script time exists, set the cut's start beside it. When a cut has moved that moment, keep the cut's time and record the script time as stale. Do not invent a timestamp or a view count.

Hand over the description ready to paste, then the chapters. Also return a separate list of every link or time still open. A link you have not opened, or that has no URL, belongs on that list. On a script with no cut, that list says the times are provisional. A title belongs to `write-video-titles`. An upload belongs to `publish-youtube-video`. This skill does not upload.
