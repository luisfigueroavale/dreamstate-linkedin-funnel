# Links

Include a resource when it helps this video. Each one has a URL you opened and a label that says what the viewer gets.

A video resource uses the full https watch URL, `https://www.youtube.com/watch?v=` plus the id. Never shorten that address.

On the owner's own site, set `utm_source=youtube` and set `utm_campaign` to the weekly campaign slug on the brief, so a signup from this video lands on that week.

A link written for the pinned comment carries its own `utm_content`. Leave every other site free of those parameters.

Copy any disclosure or credit that is already in the brief. End with one next step the brief already supports.

Do not make up a sponsor, a file to download, or a product the brief does not name.
