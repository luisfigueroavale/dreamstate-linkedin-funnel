# Opener

Start from the finished cut, or from a transcript that already carries times.

The opener is one sentence and no more than about 16 words. It says what the video is.

Build that sentence from the phrase a stranger would type, and name the main tool when the video actually uses one. Search results and the collapsed description both show this sentence alone.

The links, the next step, and the chapters come after it. Do not pack extra search phrases into it. Do not close it with a hashtag block.

A count or a metric, and any roster of tools, stays inside the video and inside the chapter labels.
