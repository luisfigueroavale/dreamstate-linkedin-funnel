# Write a video script

Write the words and the shot list the owner can record. Follow `docs/skill-frame.md`.

## Use when
- The owner needs a script before filming, after `choose-next-video` passes its three gates.

- Not for titles (`write-video-titles`), the description and chapters (`write-video-description`), the thumbnail (`design-video-thumbnail`), a render, or generated footage.

## Steps
1. Start (`references/open.md`).

2. Keep (`references/open.md`).

3. Stop (`references/open.md`).

4. Walk (`references/open.md`).

5. Say (`references/outline.md`).

6. Deliver (`references/outline.md`).

7. Write the outline in `references/outline.md`. Promise the end state first.

8. Write each beat in `references/beats.md`.

9. Match the requested runtime (`references/time.md`). Time it, then trim or restore.

10. Name the bracket, the visual, and the source (`references/deliver.md`).

11. Run (`references/deliver.md`).
## Dreamstate tools
None. Local files only.

## Stop rules
- Follow the skill-frame writing rules.

- Do not render, publish, or generate footage.

- If `audience.local/ideal-follower.md` is missing or `Status: blank`, stop and ask.

- No source means no beat.

- Never describe a broken feature as if it were shown.

- An unrun step stays unshown.

- Add no lines to fill the clock.

- Speak a number only when the source or the walk returned it.

- `write-video-description` and the chapters wait for the final-cut transcript.

- Promise only what the video can show.

- Nothing was recorded.
