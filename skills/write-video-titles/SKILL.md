# Write video titles

Build a packaging brief from outlier evidence the owner can support: two titles for a split, every claim marked, and thumbnail concepts. Follow `docs/skill-frame.md`.

## Use when

- Use before the outline.

- The owner picks what ships.

- It does not upload, and it does not invent proof.

## Steps

1. Read the Proof page before any number that would be public (`references/brief.md`).

2. Package to a filled week brief (`references/brief.md`).

3. Read the reference set with `study-thumbnail-patterns` (`references/brief.md`).

4. Resolve `source.account_posts_youtube` with `tables.executable_definitions.list_resolved`, which is a definition id, not a `tools_run` id (`references/outliers.md`).

5. Attach that definition with `tables.table_sources.attach` (`references/outliers.md`).

6. Run `tables.table_sources.run` only after the quote and the owner's yes (`references/outliers.md`).

7. Screen the rows and shortlist five to ten (`references/outliers.md`).

8. Clear the outside-niche test in `choose-next-video` gate 2 (`references/structures.md`).

9. Write Variant A, then Variant B (`references/titles.md`).

10. Judge thumbnail concepts at 320×180 (`references/thumbs.md`).

11. Hand those concepts to `design-video-thumbnail` after the owner chooses (`references/thumbs.md`).

12. Return the shortlist, both titles, the concepts, and what the owner still has to confirm (`references/thumbs.md`).

## Stop rules

- Follow the skill-frame writing rules.

- Nothing here uploads, and nothing here invents proof.

- The owner picks what ships.

- A figure that is not already cleared on the Proof page is not the owner's to claim.

- Do not invent a metric.

- Do not pass another channel's result off as this owner's.

- Do not force a three-way comparison unless the video itself is a comparison.

- This desk does not call a video-host API.

- Do not assume a browser ranking plugin is installed.

- Without those peers, the ratio is not evidence.

- If those figures are missing, leave the ratio blank rather than filling one in.

- If the evidence is missing, label the structure a hypothesis and do not treat it as validated.

- Run `tables.table_sources.run` only after the quote and the owner's yes.

- Skip the shape that treats a topic as if it had gone unsaid.

- If the buyer is a founder, leave job-ladder titles out.
