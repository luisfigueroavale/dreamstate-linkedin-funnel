# Brief

The brief is what this pass prepares. The owner picks what ships. Nothing here uploads, and nothing here invents proof. The brief holds measured outlier references, two titles for a split, and thumbnail concepts.

Before any number that would be public, read the Proof page. A figure that is not already cleared there is not the owner's to claim. The title has to stop the reader named in `audience.local/ideal-follower.md`.

If a week brief is already filled (`vault/week/<date>.md`, or `vault/week/brief.md`), package to that brief. Read the reference set with `study-thumbnail-patterns`. After the owner chooses, hand those concepts to `design-video-thumbnail` for the render.

A number inside a title stays packaging until the owner can show that number in the video. Do not invent a metric. Do not pass another channel's result off as this owner's.

Do not force a three-way comparison unless the video itself is a comparison. Set both titles before any outline exists. That outline then has to keep the promise those titles made.
