# Outliers

Outliers, only from evidence they supply or from a read that returns posts. Before hand-typed counts, resolve `source.account_posts_youtube` with `tables.executable_definitions.list_resolved`. It is a definition id, not a `tools_run` id. Attach with `tables.table_sources.attach`, then run `tables.table_sources.run` only after the quote and the owner's yes. If that definition is not resolved, they type the counts.

Take what you actually hold, in this order:

1. Outlier scores and trend views they already pasted, including a set that spans several channels. Do not assume a browser ranking plugin is installed.

2. A hand pass over the niche for the last three to six months, or that same read. This desk does not call a video-host API.

3. Channels the reader already watches.

Call a video an outlier when it sits well ahead of the rest of its own channel. Compare current views with the median of that channel's uploads of similar age and similar length, and only when at least five of those peers exist. Without those peers, the ratio is not evidence.

The ratio is views as they stand now. It is not views per hour. It is not a click-through rate. It is not evidence that the wording produced the views.

Then screen the rows yourself. Drop livestreams, anything under four minutes, and off-audience topics. Read the description and note a sponsor. Open the real thumbnail. Record the words on it, whether the subject is a face or an interface, and the one promise that picture makes.

Keep every URL. Each row also carries the views, the peer median, and the ratio they supplied. If those figures are missing, leave the ratio blank rather than filling one in. Shortlist five to ten.
