# Structures

Before a structure enters the pair, it has to clear the outside-niche test. That test is `choose-next-video` gate 2. It looks across four to six donor niches.

Keep the structure only when evidence they provided shows at least 3× from three or more channels in two or more niches, and the home niche has not already worn that shape out.

Take the shape. Leave their sentences behind.

Visible test. A trial the viewer can watch, or a question that asks for a verdict. The video runs the test and shows the verdict.

Too-easy outcome. The result is cast as almost unfairly simple. The outcome is strong, and the video really shows it.

Counted roster. A count of items, or a tally set off in parentheses. The roster is on screen.

Timeboxed volume. How much work, locked to a time box. Speed is the story.

Before-to-after. A start state, then the state after the change. One visual consequence.

Exact figure. A precise figure, where a rounded one would be weaker. Only when the video shows that figure.

Reversal. A capability stated, then why the outcome still fails. A problem set up for a new viewer.
