# Pictures

A picture only where it explains the next claim. That is a cover, or an inline frame beside the paragraph it proves. Record the cover path and each inline path on the brief. Number those inline files in article order, and add where each one sits.

Keep a caption only when it adds a fact the picture does not show. Placeholder text from an editor is not a caption. New pictures are `design-post-graphic` or `draw-process-map`. Keep the HTML. The still is the last frame of that timeline, at full size. Do not redraw it from a small export.
