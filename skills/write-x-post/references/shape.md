# Shape

Keep it short.

One post when one post can finish the idea.

A thread only when the explanation needs several distinct steps.

Number the posts in order.

The opening is a specific point the later lines can support.

Each post adds information the reader did not already have, and it connects to the post before it.

No fake cliffhanger.

No repeated conclusion.

Do not chop a LinkedIn draft into a thread.

If the claim needs the letter, link the letter.

Do not invent slang, outrage, controversy, an anecdote, or a screenshot to imitate the platform.

No invented metric.
