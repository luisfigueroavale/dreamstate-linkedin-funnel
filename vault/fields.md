# Post fields

Put these at the top of `vault/posts/<slug>.md`.

| Field | What it holds |
|---|---|
| title | Working title |
| status | Idea, Drafting, Review, Published, or Backlog |
| pillar | A name from `notes/pillars.md` |
| format | Text, portrait, carousel, or video |
| channel | linkedin, x, letter, or more than one |
| author | The person who will say it |
| publish_date | Empty until it is published. Do not invent one |
| source | A page, a file in `vault/sources/`, or a note |
| proof | Which Proof-page lines this file may use. Empty if none |

The body is the draft. A picture path, if any, points at the HTML source, not at an export.
